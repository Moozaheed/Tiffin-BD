# TiffinBD 8-Week Milestone Summary

- **Week 1**: Foundation & Infrastructure (NestJS setup, MySQL, Redis, Docker).
- **Week 2**: Authentication & Authorization (JWT, RBAC with 6 roles, User/Branch mgmt).
- **Week 3**: Order Ingestion (Connector framework: website, 3rd party, Chilli POS).
- **Week 4**: Order Processing (Normalization, routing, lifecycle mgmt).
- **Week 5**: Real-Time Notifications (Socket.IO, FCM, escalation engine).
- **Week 6**: Dashboard System (Next.js admin panel, printing integration).
- **Week 7**: Mobile App (React Native staff app, notifications, queue mgmt).
- **Week 8**: Deployment & Launch (Production Docker, monitoring, load testing).
